section: "General"

---

When you finish the final block of your active program, the app marks the block as complete and gives you two options.

### Repeat program block

Select **Repeat Program Block** if you want to run the same program again.

This restarts the block using the same structure, exercises, and schedule. This can be useful if you are still progressing and want to continue with the same program.

### Complete program

Select **Complete Program** if you want to move on from the current program.

After completing the program, you can:

* generate a new program
* create a program from scratch
* import a program

### What happens to your previous workouts?

Completing a program does not delete your workout data.

All of your logged workouts, sets, reps, and weights remain saved in your workout history and performance insights. This allows you to review past training even after starting a new program.
