The Feature Settings section lets you customize how the app works. Feature Settings control defaults, workflows, and display preferences, so the app better fits how you train and log.

You can find Feature Settings by going to **More** > **Feature Settings**.  
  
Below is a brief overview of each section.

### Dashboard

Dashboard settings control what appears on your main dashboard and how it is organized. If you want to change what you see first when you open the app or rearrange dashboard sections, start here.

### Workouts

Workout settings let you customize training defaults in more detail. This includes options like enabling rest timer sounds, disabling Smart Warm-Ups, or changing default rest timers for specific exercises. If you want to adjust how workouts behave, this is the place to do it.

### Shortcuts

Shortcuts settings control quick actions throughout the app. If you want faster access to programs or workouts and fewer taps overall, this section helps you customize that flow.

### Exercises

Exercise settings manage your exercise library. You can view existing exercises or create custom ones. If you are cleaning up your exercise list or adding new movements, this is where to go.

### Gym Profiles

Gym Profiles let you set up different training environments with specific equipment. This is useful if you train in multiple locations.

Here you can:

* Create multiple gym profiles.
* Set available equipment for each gym.
* Choose a default gym.

If you are ever unsure where a setting lives, Feature Settings is a good first place to check.
