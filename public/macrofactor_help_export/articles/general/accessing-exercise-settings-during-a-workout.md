If you need to add a note to an exercise or change a default rest timer or weight, you can access exercise settings during your workout using the steps below.

1. While in your workout and viewing the exercise, use the action bar and scroll until you see **More**.
2. Tap **Exercise Settings** to open the settings for that exercise.
3. Here, you have the option to change rest timers, add exercise notes, split left and right sets, and mark the exercise so it is not recommended.
4. Make any changes you need, then exit the screen to save them.
