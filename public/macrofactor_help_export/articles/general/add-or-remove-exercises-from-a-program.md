**To Add an Exercise**

1. Go to the **Workout** tab.
2. Tap the program you want to edit.
3. Select the workout day or rest day to which you want to add an exercise. You can add exercises to any day in your cycle.

   ![](https://staticfiles.gleap.io/gattachments/Ew3ooNoy46t7nJBhjJtLl0pL0wTLPmZ8vkylekc6nl5GjPAM3268LSLxTXsEYheL5K4YYYaoEeD.png)
4. Tap **Add Exercise** next to the exercise count for that workout.

   ![](https://staticfiles.gleap.io/gattachments/umVCBGPK8VLBLNYjkYZxWHaM6tlidumwIDQYg6YFc4z1AWc7zdW8dBCKwymGI0q9BZXRswa2AvE.png)
5. Search for the exercise you want to add, then **tap the + button** next to the exercise.

   ![](https://staticfiles.gleap.io/gattachments/MK0GWKoVS6TYOh1vHJMKEHpvABJgIYZvihKJS9CSAzMPlEkmNhTbNDPx4FksUEd1C6J5eo1rTDH.png)
6. To add multiple exercises, continue searching and **tap the + button** for each exercise you want included in your workout.
7. When you are finished, tap **Update Workout Plan** to make the exercise part of that workout, or **Start Workout** if it is a one-off addition.

   ![](https://staticfiles.gleap.io/gattachments/B38Uf888WI5FGYIQ1aekBTTyqCEfpzrBXvJQ1wrkCxIHp6vD3Ns1b7zTxbA3JgMhL18Hnozizo3.png)

**To Remove an Exercise**

1. Go to the **Workout** tab.
2. Tap the program you want to edit.
3. Navigate to the workout day you want to change.
4. Scroll to the exercise you want to remove.
5. Swipe left on the right side of the exercise and tap **Remove from workout**.

   ![](https://staticfiles.gleap.io/gattachments/sgnzUJNo7AIv3USQemVmCodEN0tIy9dWn3ytc9kFW5Pot7PUKNME6CqVqJl6IXcWcWYPrNe8xCH.png)
