You can [periodize](https://help.macrofactorapp.com/en/articles/388-how-to-enable-periodization-for-custom-programs) RIR, rep ranges, and sets for any exercise in your program, whether the program was created using Smart Generation, built from scratch, or modified by [adding](https://help.macrofactorapp.com/en/articles/292-add-or-remove-exercises-from-a-program) or [swapping exercises](https://help.macrofactorapp.com/en/articles/312-swap-exercises).

Once an exercise is part of your program, its targets can be adjusted across cycles.

You can open any exercise within a workout to adjust:

* Number of sets
* Rep minimums and maximums
* RIR targets

These targets can be set for a single cycle, multiple different cycles, or the entire program.

## Adding or fixing targets for swapped exercises in a generated program

Let’s say you used MacroFactor Workouts to generate a program, but then added or swapped an exercise. You may notice that the new exercise does not have auto-populated sets, reps, or RIR targets like the rest of your generated program.

This does not mean the exercise cannot be periodized, you just have to make a few manual adjustments because you’ve now customized the program.

To add targets:

1. Go to the **Workout** tab.
2. Select the program you want to edit.
3. Navigate to the exercise you want to add targets to.
4. Select inside the cycle box.

   ![](https://staticfiles.gleap.io/gattachments/88j9acJ5SXB2eKwQYIMi5uQ6E4l4AQlqdoth3WIr6F0UFriOiB3ibaX79lEasezl6SnKnhlX9mj.png)
5. Adjust the sets, reps, and RIR as desired.

   ![](https://staticfiles.gleap.io/gattachments/swZFs2Ne8AdOoABLIRp6ZWGZDqbXTs2clTpDhYcqXeCX1ZDUcIxUpgfFbOE1VMqlGINCu9Fcnsn.png)
6. Tap **Save** or **Save to All Weeks.**

## Changing targets for a specific week

Now, let’s say that in **week 3**, you want to change things up.

You can do that without changing the rest of the program:

1. Go to the **Workout** tab.
2. Select the program you want to edit.
3. Navigate to the exercise you want to adjust.
4. Scroll through the cycle weeks and select the cycle box of the week you want to modify (for example, week 3).

   ![](https://staticfiles.gleap.io/gattachments/2msU6G3YMUasb9CKMQyC6ggOsVbqgeSQtIg7cI0S8hTI00jJIsLBZfZ1l5RvP7JFbdD7JlcdJ0h.png)
5. Edit the targets for that cycle.

   ![](https://staticfiles.gleap.io/gattachments/g8pt5jqBmqvbXJhuuBZFtIliNp3e34vLsI8oZRDOsI4v9NZrgv0s8DnKOFMHZJnVYfQCQmnNCHq.png)
6. If you save the changes for that cycle only, you’ll see them affect only that cycle.

   ![](https://staticfiles.gleap.io/gattachments/XWxaX45kfWmfHoydXRuvTZBywjwb5AHsfvmzk5VHgpjUUvTmrFMtBKvkkBv7VVHtzbBzqDZW8qm.png)

You can also apply those changes to **all exercises for that day**. This works well if you want to test a specific training approach, such as increasing effort or using a single week, without affecting the rest of your cycles.

## Understanding target save options

When you edit an exercise’s targets, you can choose how broadly those changes apply:

* **Current cycle only:** Applies the changes to that one cycle (week).
* **All cycles for that exercise:** Sets consistent targets for that movement across the entire program.
* **All exercises for the day**: Saves for all exercises in that current cycle, but none before or after.
* **All exercises and all cycles:** Applies the same sets, reps, and RIR to every exercise in the program. This option updates all exercises and cannot be undone, so use it carefully.
