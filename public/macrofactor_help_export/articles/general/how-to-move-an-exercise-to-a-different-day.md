If you want to move an exercise to a different workout day, you can do so without deleting it from the whole program.

1. Go to the **Workout** tab.
2. Select your active program.
3. Navigate to the workout day that contains the exercise you want to move.
4. **Tap the three dots** next to the exercise you want to move.
5. Select **Move to a different day**.
6. Select the workout day you want to move the exercise to.
7. The exercise will be moved immediately.
