After you finish logging a set, the default rest timer starts counting down in the top-right corner of the screen. If you want to adjust the rest time, you have a few options:

1. Tap the rest timer in the top-right corner.

   * Add or subtract 10 seconds.
   * Restart the timer using preset intervals, including 15-second increments up to three minutes.
2. After you select a new rest time, the rest timer menu closes and returns you to your workout.

If you want to change the default rest timer for an exercise or style of lift, you can find instructions [in this article.](https://help.macrofactorapp.com/en/articles/303-change-default-rest-timers)
