## Set Types in Workouts

MacroFactor Workouts supports several different set types. Each set type reflects a specific training intent and can affect how the set behaves when you log it during a workout.

**You can read more details about each training type** [**here**](https://help.macrofactorapp.com/en/articles/379-what-are-myo-reps-drop-sets-and-failure-sets)**.**

## **Selecting different set types**

When creating a program or workout, or during an active workout, you can select different set types by tapping the set number.

![](https://staticfiles.gleap.io/gattachments/ExOkHfTUsDmbqamV60QfhDeq5YGnB0lb0YsitMLucfD8CWhQWrHhOH7de6cUUzPhvBfE8OjBMoI.png)

Tapping the set number will bring up different set types.

![](https://staticfiles.gleap.io/gattachments/XECuty0zFoVFvKDqeCZvo5MLh2nrzEMIcWatNgIsLvgOEdsfpujWV3YUNX6vSV2RBIgx492Zz7w.png)

### **Standard set**

This is the default set type with a fixed weight and target rep range. You enter the weight and reps you performed, then mark the set as complete.

### **Warm-up set**

A lighter set used to prepare for heavier working sets.

Warm-up sets are labeled with a **W**. The weight is lower than your standard working sets and is intended to help you ease into heavier loads.

![](https://staticfiles.gleap.io/gattachments/AdT3zVplIsXnnn1QMrjFKhEFOZf5uZddXQNIvJqfWlDmmkyII99FdgdaLRq4L5TaWYlk75E4hDm.png)

### **Drop set**

A set where you continue repping with progressively lighter weights after reaching failure or near failure at a heavier load.

[Drop sets](https://help.macrofactorapp.com/en/articles/379-what-are-myo-reps-drop-sets-and-failure-sets) are labeled with a **D** and appear as a single set with multiple weight and rep entries. You log each weight decrease, and all entries are grouped together as one set.

![](https://staticfiles.gleap.io/gattachments/5p3x2rH8zPdNJFc6yXpQYjDAPTyVKc7kYgRRcqdMevMaDSWqmwUl4pGOCFskaqVeqPwr9yYfQbc.png)

### **Myo set**

A set where you perform an initial set, then continue repping with the same weight after very short rest periods.

[Myo sets](https://help.macrofactorapp.com/en/articles/379-what-are-myo-reps-drop-sets-and-failure-sets) are labeled with an **M**. You can log multiple brief rest-pause efforts at the same weight. Each entry represents another continuation, and all entries are grouped together.

![](https://staticfiles.gleap.io/gattachments/rKvkXPKPlkwsfc0qdm1XI4xmbeme7gwaYRYVm5HMw6y4BzCqsS6AfkmNhG03jVM0Y7SY32hQw1T.png)

### **Failure set**

A set performed until you can no longer maintain proper form for the exercise, also known as technical failure.

[Failure sets](https://help.macrofactorapp.com/en/articles/379-what-are-myo-reps-drop-sets-and-failure-sets) are labeled with an **F**. You log the weight and reps at an RIR of zero to indicate the set was taken to technical failure.

![](https://staticfiles.gleap.io/gattachments/h6ozzGsJRGsWRGdTfQKp5zuMGtzlkADkwBkiOSTOzdECnz48wOiB4haaUfY9OUzqRtOSKCed7D4.png)
