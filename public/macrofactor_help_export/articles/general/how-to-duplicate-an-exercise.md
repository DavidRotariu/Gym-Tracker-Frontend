---
title: "How to Duplicate an Exercise"
section: "General"
source_url: https://help.macrofactorapp.com/en/articles/386-how-to-duplicate-an-exercise
---

1. Go to **More** > Feature Settings > **Exercises**.
2. Search for the exercise closest to the one you want to create/duplicate and **tap the exercise.**
3. Select Edit Duplicate.
4. On the custom exercise creation screen, enter the exercise name and select a trackable metric, such as reps or weight. Then choose the exercise type, for example, compound upper or lower, isolation upper or lower, or core, and select laterality, such as bilateral, unilateral, asymmetrical, or both unilateral and bilateral. **Note: For a duplicate exercise, most of this will stay very similar.**
5. Select the muscle groups the exercise targets.
6. Tap a muscle icon once to mark it as a primary muscle group. A **P** will appear in the box to indicate it is primary.
7. Tap the icon again to mark it as a secondary muscle group. An **S** will appear in the box to indicate it is secondary. If you tap a third time it will unselect the muscle altogether.
8. Add resistance equipment if needed, such as a dumbbell, kettlebell, or barbell. Toggle **Bodyweight Exercise** if no external resistance is used.

   **Note: This is where most changes occur if you want to do the same exercise with a different machine or added support.**
9. On the final details screen, optionally set the range of motion, stability, body weight contribution, movement pattern, alternate names, and description.
10. Review the exercise overview. If everything looks correct, tap **Create Exercise** to save.
