1. Go to the **Dashboard** tab.
2. Scroll down to **Exercises**.
3. Tap **See all**.
4. View detailed stats and multiple performance metrics for each exercise.

Available views include:

* **1-RM, 3-RM, and 10-RM estimates:** Tracks changes in your estimated strength across different rep ranges.
* **Total Volume:** The total amount of weight lifted for that exercise over selected time periods.
* **Best Set Volume:** The highest single-set volume you have recorded.
* **Heaviest Weight:** The maximum load you have used for that exercise.
* **Total Reps:** The total number of reps completed over selected time periods.
* **Best Set Reps**: The highest number of reps you’ve recorded in a single set.
* **Total Sets:** The total number of sets you have performed to date.

In each of these views, you can adjust the time range to see averages over short or longer time periods as well as monthly recaps.
