If you want to update the name of a workout, you can rename it directly from your program without changing the workout itself.

1. Go to the **Workout** tab.
2. Select the program that contains the workout you want to rename.
3. Do not expand the program from the side. Tap the program itself to open it.
4. Use the top workout navigation to locate the workout you want to rename.
5. Tap the workout you want to rename, tap **Rename** in the action bar.
6. Enter the new workout name, then tap **Save**.
