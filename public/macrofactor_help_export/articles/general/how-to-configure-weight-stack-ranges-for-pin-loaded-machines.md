You can customize the available weights for pin-loaded machines in your gym profile to match the weight stack ranges available in your gym.  
  
This can be helpful because different machines may have different weight ranges and increment patterns. For example, one machine may increase in 5 lb increments from 15 to 25 lb, 10 lb increments from 25 to 55 lb, and 15 lb increments from 55 to 190 lb.

## To edit a machine’s weight stack ranges:

1. Go to **More > Gym Profiles**
2. Tap the pencil icon next to the gym profile you want to edit
3. Locate the machine you’d like to edit and tap **Edit Machine**

Using those steps, you’ll be brought to the weight stack range setup menu for that machine.  
  
Each machine will have a default weight stack range, but your can edit the existing range, add additional ranges manually, add additional ranges using the Scan with AI tool, remove ranges, and add micro adjustments.

## To add a new weight stack range:

1. Tap the + icon in the top-right corner of the weight stack range menu
2. Tap **Add Weight Stack Range**

   ![](https://staticfiles.gleap.io/gattachments/IQ75IfE0GxuBOamjqGFEl9Tge0MiV5q7mSWWPpFWcukAj4LLkloKKgQEdC2ZHxiG12T5BgfhMPk.png)
3. Enter the range start weight
4. Enter the range end weight
5. Enter the increment for that range

For example, if a machine goes from 15 lb to 25 lb in 5 lb increments, you would enter:

Range Start: 15 lb  
Range End: 25 lb  
Increment: 5 lb

This would create available weight options of 15, 20, and 25 lb. If that same machine then goes from 25 lb to 55 lb in 10 lb increments, you can add another range for that section of the stack.  
  
You can also use **Scan with AI** to help generate weight stack ranges from a photo. To scan a weight stack:

1. Tap **Scan with AI**
2. Capture a photo of the weight stack, or upload an existing photo
3. Choose your unit preference
4. Add a short description, if needed
5. Tap **Analyze**

If you need to remove a weight stack range you can swipe left on the range you want to remove, and then tap on the remove icon.

## **Adding Micro-Adjustments**

Some machines allow for smaller weight adjustments in addition to the main weight stack. You can add these as micro adjustments by using the following steps:

1. Tap the + icon in the top-right corner
2. Tap **Add Micro-Adjustment**
3. Select the type of micro adjustment you wish to add

   ![](https://staticfiles.gleap.io/gattachments/arAqpaap5Z0ZD8Xbck56Ys0b9tIHfKKPyH8q0eSuhIp1fEuIXDTg2AS54LJAWk4q7S0UBGi9Krk.png)

There are *three* types of micro adjustments currently available:

**Dial** - This fine-tunes the weight using a small adjustment dial on top of the selected load. This allows one adjustment at a time.  
  
**Selectorized Pin** - This lets you select a single incremental weight by inserting a pin into the micro adjustment stack.  
  
**External Plates** - This is used when you load additional plates directly onto the machine. This allows more than one adjustment at a time.

4. Once you’ve selected the micro-adjustment type, enter the weight for that adjustment
5. To add more micro-adjustments, tap on **+ Add Weight**, or tap **Done** to save your changes.
