MacroFactor Workouts allows you to share programs and individual workouts with other users by [exporting them](https://help.macrofactorapp.com/en/articles/287-how-to-import-a-workout-or-program) as spreadsheet files. Once shared, anyone can import the program or workout spreadsheet file into their own app.

To share a program or workout, you’ll first need to export it from your app. To do so:

1. Go to the Workout tab.
2. Open the workout or program you want to export.

**For programs**: Tap **Program Settings** in the top-right corner, scroll down, and tap **Export Program**.

**For workouts**: Tap the three dots at the top of the workout, scroll down, and tap **Export Workout**.

Once the file has been exported, you can share it using your preferred method of sharing.

Then, the user can import a program or workout.

*Note: Do not use the program import option for a workout or the workout import option for a program.*

1. Tap the + icon

For programs: Tap **New Program**, and then select the **Import from File** option. Once you’ve done that, you can upload the program file and tap **Save to Library**, or **Activate Program**.

For workouts: Tap **New Workouts**, and then select the **Import Workout From File** option. Once you’ve done that, you can upload the workout file and tap on **Save to Library**.

## Importance regarding formatting requirements:

In order for the import to succeed, the file must follow the required formatting. You’ll want to avoid changing the overall formatting, including exercise names or column headers.

Another thing to note is that if a shared program or workout includes custom exercises, the import may fail if the receiving user does not already have those same custom exercises in their own exercise database.

Right now, the safest option is to remove any custom exercises from the exported spreadsheet before sharing it. The receiving user can then either:

1. Add the custom exercises manually within their own app.
2. Replace those exercises with alternatives from the existing exercise database.
