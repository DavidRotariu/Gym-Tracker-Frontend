You may want to create a new program that is very similar to an existing one, but with small changes in exercise selection or weekly structure. Duplicating a program lets you save time instead of starting from scratch.

1. Go to the **Workout** tab.
2. Select the program you want to duplicate.
3. Tap the **settings icon** in the top-right corner.
4. Tap **Duplicate Program**.
5. Enter a name for the duplicated program.
6. Tap **Save & Go to Duplicate**.
