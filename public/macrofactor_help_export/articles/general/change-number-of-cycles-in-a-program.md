Changing the number of cycles in a program lets you control how long the program runs before it resets. From a preference standpoint, shorter programs can feel easier to commit to or review more often, while longer programs reduce the need for frequent changes. From a training standpoint, shorter cycles can be useful when you want to experiment with new exercises, adjust volume sooner, or run focused blocks, while longer cycles can support consistency, gradual progression, and reduced decision-making over time.

1. Go to the **Workout** tab.
2. Tap the program you want to edit.
3. Tap the **program settings icon** in the top-right corner.

   ![](https://staticfiles.gleap.io/gattachments/tSoPLuuUMosjYCJL4rYEKd92sxnciMYQojtkiTggr49uALNCC4JedSgfKudzwoHqexMFwb4TbEl.png)
4. At the top of the settings screen, adjust the number of cycles using the **+** or **-** buttons.

   ![](https://staticfiles.gleap.io/gattachments/95B44XPJ78cwSE4CuoTkYAgn1tTJ95ysu6M7yJLl6P0jUONF5hS8WULfZ8f0eSMRrJs7hG6B340.png)
5. You can set the number of cycles anywhere from 1 to 52.
6. Tap **X** to save and close program settings.
