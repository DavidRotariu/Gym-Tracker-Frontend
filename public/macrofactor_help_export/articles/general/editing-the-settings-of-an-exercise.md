There are several settings you can adjust for exercises. To edit an exercise, go to **More** > Feature Settings > **Exercises** and select the exercise you want to update. Once selected, you will see the following options:

**Info**: View exercise instructions, details, and history.

**Weights**: Set the weights that will be used during the workout.

**Rest Timer**: Change the rest duration between sets.

**Rest Between Left/Right Sets**: Used for unilateral exercises (for example, lunges or single-arm presses). This controls how long you rest before switching sides.

**Exercise Note**: Add a note that appears each time you perform the exercise.

**Do Not Recommend**: If you toggle this, the exercise will not be recommended when creating programs.  
**Edit Duplicate**: Creates a copy of the exercise and opens the custom exercise creation screen to make changes.
