Each rest timer has a default duration based on the movement type. For example, lower body compound exercises default to 3:00, while upper body isolation exercises default to 1:30.

**To change default rest timers**

**Option 1:** 

1. Go to **More** > Feature Settings > **Workouts**
2. Scroll down to **Rest Timer,** then tap **Timer Duration**.
3. You’ll find a list of **Default Timers**.
4. Tap **Edit** beside to adjust any default timer durations as desired.
5. Tap **Save** when finished.
6. To return to the original settings, tap **Reset Defaults**.

**Option 2:**

1. Go to the **Workout** tab.
2. Start a workout.
3. Tap the three horizontal lines in the top-left corner of the screen.
4. Select **Workout Settings**.
5. Scroll down to **Rest Timer,** then tap **Timer Duration**.
6. You’ll find a list of **Default Timers**.
7. Tap **Edit** beside to adjust any default timer durations as desired.
8. Tap **Save** when finished.
9. To return to the original settings, tap **Reset Defaults**.

**To add an exercise-specific rest timer**

**Option 1:** 

1. Go to **More** > Feature Settings > **Workouts**
2. Scroll down to **Rest Timer,** then tap **Timer Duration**.
3. Under **Exercise Timers**, next to **Add Exercise Timer**, tap **Add**.
4. Search for and select the exercise you want to customize.
5. Set your desired rest timer duration for that exercise.
6. Tap **Add Custom** **Rest Timer** when finished.

**Option 2:**

1. Go to the **Workout** tab.
2. Start a workout.
3. Tap the exercise you want to add a custom timer to from the top navigation bar.
4. Scroll to the end of the action bar, under the exercise title, tap **More > Exercise Settings**.
5. Next to the **Rest Timer,** tap **Edit**.
6. Set your desired rest timer duration for that exercise.
7. Tap **Save** when finished.
