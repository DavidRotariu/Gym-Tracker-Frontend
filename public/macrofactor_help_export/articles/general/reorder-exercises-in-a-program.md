title: "Reorder Exercises in a Program"
section: "General"
source_url: https://help.macrofactorapp.com/en/articles/296-reorder-exercises-in-a-program
---

1. Go to the **Workout** tab.
2. Tap the program you want to edit (for example, *Beginner Full Body*).
3. Select the workout day you want to rearrange (for example, *Workout A*).
4. Tap **Reorder** from the action bar.
5. Press and hold an exercise, then drag it into the order you want.
6. Tap **Done** when you are finished.
